# AJ Money Management Android App

This repository contains an Android WebView wrapper around the supplied AJ Money Management HTML app.
The supplied AJ Money Management image is used as the launcher icon.

## Build APK with GitHub
1. Upload the complete contents of this folder to a GitHub repository.
2. Open the repository's **Actions** tab.
3. Select **Build AJ Money Management APK**.
4. Press **Run workflow** (or push to the `main` branch).
5. When the workflow completes, open the run and download the `AJ-Money-Management-APK` artifact.

The APK is a debug build for testing and sideloading. A signed release build is a separate step.
